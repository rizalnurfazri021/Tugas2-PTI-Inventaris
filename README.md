# Tugas 2 PTI - Sistem Inventaris Barang

Aplikasi Sistem Informasi Manajemen Data Sederhana (Inventaris Barang) menggunakan PHP Native dan MySQL.

* **Password:** admin123

## Cara Menjalankan
1. Import file `inventaris_db.sql` ke dalam database MySQL (phpMyAdmin/HeidiSQL).
2. Pastikan konfigurasi di file `db.php` sudah sesuai dengan database lokal Anda (user: root, pass: kosong).
3. Letakkan folder project di dalam direktori `htdocs` (XAMPP) atau `www` (Laragon).
4. Buka di browser melalui `localhost/nama_folder_anda/login.php`.
